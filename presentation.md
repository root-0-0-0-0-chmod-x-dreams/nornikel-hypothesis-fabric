# Слайды по стеку

---

## Фронтенд

Одностраничное приложение (React 19, TypeScript 6, Tailwind CSS v4, Vite). Чат-интерфейс с потоковым выводом (SSE). Загрузка документов: drag-and-drop файлов и по URL с автоэкстракцией контента и прогресс-баром. Превью документа: три вкладки — Инфо (метаданные), Контент (рендеринг Markdown с кодом, таблицами, формулами), Файл (просмотр PDF и изображений). Дорожная карта: вертикальный таймлайн с этапами, ресурсами и критериями успеха/провала. Glassmorphism-дизайн, тёмная тема, ресайзабельные панели (до 35%/45% экрана), персистентность через localStorage.

## LLM-сервис

FastAPI (Python 3.11) как шлюз к моделям. Два режима: синхронный чат и потоковый (SSE). Поддерживает системные промпты, историю диалога и вложения (изображения для VLM). OpenAI-совместимый API для простой интеграции. Менеджер моделей с отслеживанием статуса (available, unavailable, rate_limited), автоматический fallback при недоступности. Очередь с asyncio.Semaphore для соблюдения лимитов провайдера. Структурированное логирование (JSON) с трейсингом запросов. Health-check эндпоинты для Docker.

## Content Extraction

FastAPI (Python 3.12). Выделенный сервис извлечения контента из веб-страниц. Headless Chromium через Playwright с пулом из 4 страниц для параллельной обработки. Страница рендерится полностью (включая JS), затем контент извлекается алгоритмом Readability (Mozilla) и конвертируется в Markdown. Метаданные: заголовок, описание, автор, язык, canonical URL, HTTP-заголовки. Поддержка стелс-режима (обход защиты от ботов). Возвращает структурированный JSON: url, title, markdown, text, excerpt, html, metadata, status_code.

## Data Pipeline

Предобработка всех входящих документов в единый формат Markdown. PDF — через opendataloader, DOCX — через docx2md, XLSX — через openpyxl и pandas с сохранением привязки к ячейкам. Изображения (PNG/JPG) передаются VLM-модели Qwen 3.6 35B для получения текстового описания. Чанкинг: текст разбивается на фрагменты с метаданными (заголовок, подзаголовок, источник, номер страницы) и search-полями (summary, questions). Аналитический пайплайн для Excel-таблиц флотации: парсинг по структурным правилам (колонки металлов, строки-категории, фракции крупности), гибридный режим с LLM и детерминированным fallback-парсером.

## RAG и векторный поиск

Гибридный поиск в Qdrant: BM25 (разреженный, ключевые слова) и dense embeddings (плотный, семантический). Результаты объединяются через weighted Reciprocal Rank Fusion, затем graph-overlap rerank и MMR-диверсификация для устранения дублей из литературы. Provenance: каждый чанк несёт citation с привязкой к странице, параграфу или ячейке Excel. При retrieval подсвечивается overlap с запросом.

## Граф знаний и GraphRAG

Онтология обогащения: Factory, LossForm, Mineral/Metal, Mechanism, Process, Equipment. Собирается из Excel (структурный парсинг) и wiring-каталога. PDF линкуется через keyword linker (EVIDENCED_BY), без NER по всему корпусу. Граф на Neo4j / networkx. GraphRAG стартует от LossForm bucket, обходит граф на 2-3 hop по паттерну Swanson ABC (форма, механизм, интервенция), фильтрует оборудование по constraints фабрики, подмешивает budget/regulation чанки. Поддержка multi-hypothesis: несколько перефраз от LLM с fused evidence по каждой ветке. Результаты графового поиска сливаются с гибридным через RRF и реранжер.

## LLM-агенты

Три агента на DeepSeek V4 в цикле взаимной проверки. Agent 1 (Generator): получает запрос и чанки из БД, генерирует Top-N гипотез с формулировкой, механизмом и ссылками; может вызывать VLM для анализа схем. Agent 2 (Actor): проверяет каждую гипотезу — поиск источников в БД, Google Scholar и Arxiv, верификация ссылок, формирование обоснования; отбрасывает гипотезу если не может устранить замечания Judge. Agent 3 (Judge): критикует по пяти метрикам — полнота обоснования (0.5), наличие ссылок (блокирующая), механизм и новизна (0.3), риски (блокирующая), ценность/KPI (0.2). Цикл Actor-Judge до достижения порогов.

## Инфраструктура

Docker Compose — все сервисы одной командой. Nginx как API Gateway: проксирует запросы к LLM-сервису (порт 8000) и сервису экстракции (порт 8005), отключает буферизацию для SSE-стриминга. Локальное развёртывание — конфиденциальные данные не покидают контур предприятия. Масштабирование на новые предметные области через конфигурацию графа знаний и доменных онтологий без перестройки ядра. Поддерживаемые языки: русский, английский, китайский.
