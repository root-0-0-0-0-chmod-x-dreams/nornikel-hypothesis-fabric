При нарушении режима перемешивания (например, в случае прекращения подачи воздуха) нижняя часть аппарата может забиться осевшими твердыми частицами. Для их взмучивания служит диспергатор, с помощью которого в нижнюю, коническую часть днища агитатора при необходимости можно подавать сжатый воздух.
