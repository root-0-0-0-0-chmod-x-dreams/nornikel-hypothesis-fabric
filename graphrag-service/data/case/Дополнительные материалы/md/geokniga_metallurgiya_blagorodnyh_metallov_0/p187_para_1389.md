В некоторых случаях печи Эдвардса имеют специальные приспособления для изменения угла наклона печи, что позволяет регулировать скорость прохождения материала через печь при изменении вещественного состава обжигаемого концентрата. На предприятиях небольшой производительности (до 7…10 т/сут концентрата) использовались печи с одним рядом гребков; при более высокой производительности (10…50 т/сут) устанавливали печи с двумя рядами гребков.
