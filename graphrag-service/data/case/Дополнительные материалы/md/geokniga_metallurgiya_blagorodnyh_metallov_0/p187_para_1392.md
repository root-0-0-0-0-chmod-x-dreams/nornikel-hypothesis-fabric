Многоподовая печь (рис. 10.3) представляет собой вертикальный стальной цилиндр диаметром 6,8…8,7 м и высотой до 10,5 м, внутренняя поверхность которого футерована шамотным кирпичом. По высоте печь делится на отдельные этажи сводами из фасонного шамотного кирпича, причем свод нижележащего этажа служит подом для вышележащего. Таких подов делают несколько – от 7 до 12. Верхний свод служит для подсушивания концентрата и поэтому называется подсушивающим, делается он обычно из стали.
