Характерно, что процесс взаимодействия минералов меди с цианистыми растворами резко замедляется при уменьшении концентрации цианида. Это иногда используют для извлечения золота из медистых руд, обрабатывая их слабыми цианистыми растворами, – метод обратного выщелачивания.
