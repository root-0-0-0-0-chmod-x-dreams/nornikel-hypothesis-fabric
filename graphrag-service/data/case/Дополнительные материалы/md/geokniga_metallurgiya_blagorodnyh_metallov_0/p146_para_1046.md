Подобно ионообменным смолам, активные угли применяют для сорбции благородных металлов непосредственно из пульп. Эта технология, аналогичная рассмотренной выше технологии с применением ионитов, в последние годы все шире распространяется на зарубежных золотоизвлекательных предприятиях (США, Австралии, ЮАР и других стран).
