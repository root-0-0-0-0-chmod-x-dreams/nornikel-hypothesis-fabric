section: "Поведение сульфидов железа при цианировании руды"

Выщелачиванию в чанах подвергается материал, для которого скорость просачивания растворов составляет не менее 1,8 см/ч. Материал, уровень раствора над которым понижается медленнее, на практике считают невыгодным для обработки перколяцией. В некоторых случаях для ускорения перколяции и улучшения аэрации применяют отстаивание растворов.
