Отобранную пробу отливают в изложницу в виде тонкого слитка. Быстрое охлаждение такого слитка обеспечивает достаточную однородность сплава. Пробу для анализа отбирают в виде стружек или опилок. Результаты анализа необходимы для точного учета количества благородных металлов, поступивших в аффинаж, и расчета с поставщиками.
