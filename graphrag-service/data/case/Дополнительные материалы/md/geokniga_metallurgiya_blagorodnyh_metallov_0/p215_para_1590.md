2NaAu(CN)2 + Zn = 2Au + Na2Zn(CN)4. Аналогично извлекается серебро. Растворы, поступающие на осаждение цинковой пылью, должны содержать золота не ниже 0,4…0,5 мг/дм3, цианида (по NaCN) не ниже 0,03–0,05 %, щелочи (по СаО ) в пределах 0,0012–0,02 % и растворимого кислорода не более 0,5…2 мг/дм3 .
