Иногда руды, представляющие упорный материал для цианирования, легко подвергаются обогащению. Так, например, золото, ассоциированное с сульфидами, может быть достаточно полно извлечено из руды методом флотации. Медленно растворяющееся в цианиде крупное золото, а также золото, покрытое поверхностными пленками, хорошо извлекается в гравитационные концентраты.
