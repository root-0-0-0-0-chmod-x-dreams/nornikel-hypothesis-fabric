Большое значение для смачиваемости золотых частиц имеет состояние поверхности ртути, употребляемой для амальгамации золота. Ртуть должна быть подвижной, иметь свежую блестящую поверхность. Будучи механически разбита на мелкие капли, она должна при контакте отдельных капель быстро сливаться в одну массу.
