Между собой этажи сообщаются отверстиями в сводах, расположенных в центре печи или по периферии попеременно. На уровне каждого этажа боковые стены печи имеют 4–8 рабочих окон с дверками, в которых находятся небольшие отверстия с заслонками для наблюдения.
