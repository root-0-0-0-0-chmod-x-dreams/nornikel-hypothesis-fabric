[Cu(NH3)4]SO4 + 2Na2S2O3 + 4H2O = Na2[Cu(S2O3)2] + Na2SO4 + 4NH4OH. Реакция растворения золота при этом выглядит так: Au + 2Na2S2O3 + Na2[Cu(S2O3)2] = Na3[Au(S2O3)2] + Na3[Cu(S2O3)2].
