Биологическая обработка сточных вод успешно используется на одной из фабрик в США. На обработку поступают как стоки текущего производства, так и воды из хвостохранилиша. Разница температур этих растворов может достигать 50°, значения рН для заводских стоков 5…5,6, а для вод хвостохранилища – 7…9,5.
