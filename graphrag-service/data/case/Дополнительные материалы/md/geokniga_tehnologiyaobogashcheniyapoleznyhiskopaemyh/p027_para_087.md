После каждой изученной темы студенту предлагается проверить уровень усвоения пройденного теоретического материала. Для этого после каждой темы выполняют тестовые задания с помощью специальной тестовой программы UniTest, разработанной в лаборатории по разработке мультимедийных электронных образовательных ресурсов ИАД СФУ.
