Своеобразная конструкция машины пенной сепарации, так называемый глубокий пенный сепаратор МПСГ, разработана институтом Госгорхимпроект для решения обратной задачи — не для флотации сверхкрупных частиц, а для флотационного выделения тонких глинистых шламов из сильвинитовой пульпы. Эта конструкция отличается большой высотой камеры (6 м), высокой производительностью.
