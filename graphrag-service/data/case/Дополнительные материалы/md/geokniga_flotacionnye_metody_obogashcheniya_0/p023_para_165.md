В графите (рис. 3) атомы углерода расположены слоями, образующими гексагональную сетку. В плоскости этих слоев (заштрихованных) между атомами углерода имеются сильные атомные связи, однако связь между слоями осуществляется слабыми молекулярными силами. Этим объясняется легкая раскалываемость графита по плоскости спайности, проходящей между слоями, и гидрофобность его поверхности, совпадающей с плоскостью спайности.
