В количествах, превышающих обычные для флотации (например, при расходе 1,1 — 1,2 кг/т), жидкое стекло обычно уже не проявляет избирательности действия. Но при высоких температурах (выше 60 °С) оно при больших расходах десорбирует собиратель с кальцита («процесс Петрова»).
