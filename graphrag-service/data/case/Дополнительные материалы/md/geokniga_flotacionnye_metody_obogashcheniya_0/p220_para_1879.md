Эжекторные флотационные машины используют для аэрации пульпы струйные насосы, через которые прокачивается пульпа, эжектирующая воздух из атмосферы. Воздух диспергируется при турбулентном течении пульпы с большой скоростью. Специальное очертание диффузора (наличие в нем сужения) вызывает растворение части пузырьков. При выходе пульпы из эжектора давление падает, и происходит значительное выделение газов из раствора (до 20 г газов из 1 м3 пульпы). Это приводит к улучшению извлечения из пульпы тонкодисперсных шламовых частиц.
