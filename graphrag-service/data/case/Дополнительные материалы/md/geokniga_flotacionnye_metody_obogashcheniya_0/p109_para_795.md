Для своего времени эта теория была весьма прогрессивной и указала пути для создания научно обоснованных взглядов на важнейшую для флотации область взаимодействия минералов с реагентами. Большой заслугой этих ученых было также привлечение внимания исследователей к химии флотации, являющейся одной из главных сторон этого процесса.
