Флотацию кварц-флюоритовых руд осуществляют по простой схеме, состоящей из основной, контрольной и перечистных операций. В тех случаях, когда в руде есть сульфидные минералы (чаще всего пирит), их выделяют в пенный продукт в первых камерах с помощью ксантогенатов, иногда после предварительной сульфидизации.
