Вначале, до соприкосновения гидратных оболочек частицы и пузырька, утончение прослойки воды между ними происходит без возрастания свободной энергии этой прослойки, поскольку удаляется вода, молекулы которой легкоподвижны. Начиная с точки б, свободная энергия возрастает. Для компенсации временного возрастания свободной энергии системы приходится затрачивать дополнительную энергию.
