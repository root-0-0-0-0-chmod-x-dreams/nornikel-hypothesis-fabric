Механизм взаимодействия ионогенных собирателей с минералами. Каждая группа собирателей в зависимости от состава и свойств их солидофильной группы имеет определенные, присущие только ей особенности взаимодействия с минералами. Одиако сначала целесообразно рассмотреть некоторые положения, общие для всех ионогенных собирателей, характеризующие механизм их закрепления на минералах.
