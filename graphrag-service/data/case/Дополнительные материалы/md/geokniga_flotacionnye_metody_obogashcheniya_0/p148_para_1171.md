Некоторые реагенты-регуляторы используются при флотации как пептизаторы шламов для ослабления их отрицательного влияния на результаты флотации. В пептизированном состоянии шламы не флотируют и меньше влияют па флотацию частиц обычных для флотации размеров. Пептизирующим действием обладают некоторые электролиты, причем для эффективной пептизации необходимо, чтобы один из ионов электролита-пептизатора был бы потепциалопределяющим по отношению к пептизируемому веществу.
