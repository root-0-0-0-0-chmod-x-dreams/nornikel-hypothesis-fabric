Сплошные колчеданные руды с высоким содержанием пирита, где медь представлена первичным халькопиритом, можно флотировать по схеме прямой селективной флотации с применением бесцианидных реагентных режимов. Вкрапленные медно-цинковые руды обогащают по схемам коллективно-селективной флотации.
